About Me

Quality isn't a phase — it's a mindset. As an SQA Engineer based in Lahore, I've spent 3+ years embedded in development teams, learning what breaks software and, more importantly, how to stop it from ever reaching users. I've worked across industries — SaaS, fintech, blockchain, and real-time communication — adapting my testing approach to every domain.

What sets me apart is how I think like a user and test like an engineer. I map business requirements to edge cases, validate complex API flows in Postman, and ensure every release is backed by solid regression coverage. I also have basic hands-on knowledge of test automation using Playwright, which I'm actively building on. Whether onsite at Spadasoft or remote with UpToData, I've built a reputation for thorough documentation, fast defect turnaround, and clear communication about release risks.
